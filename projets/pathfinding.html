Pathfinding Sandbox

Deux bacs à sable, l'un en 2D et l'autre en 3D, pour expérimenter la recherche de chemin avec l'algorithme A*. On crée des agents, on leur donne des objectifs et des patrouilles, puis on modifie le terrain pendant qu'ils se déplacent pour les voir recalculer leur chemin.

C++A*IASFMLDirectX 12
Équipe binôme avec Vivien Singier

Fonctionnalités

Ce qu'on peut faire

Agents

Créer, sélectionner et supprimer des agents, régler leur vitesse.

Objectifs

Donner une destination à un agent, puis enchaîner des destinations secondaires.

Patrouille

Un agent peut boucler sur ses objectifs en continu.

Aperçu

Afficher le chemin prévu avant que l'agent ne parte.

Éditeur de carte

Rendre une case franchissable ou non et, en 3D, changer sa hauteur. Les cartes se sauvegardent et se rechargent.

Chemins dynamiques

Quand le terrain change ou qu'un autre agent bloque le passage, l'agent corrige son chemin ou fait un détour.

L'algorithme

A* sur une grille

Chaque case de la grille est un nœud relié à ses voisines, diagonales comprises. A* explore en priorité les nœuds qui semblent les plus proches de l'arrivée, ce qui lui évite de parcourir toute la carte.

Choisir le prochain nœud

La file de priorité trie les nœuds selon le coût déjà parcouru plus la distance estimée jusqu'à l'arrivée. En cas d'égalité, elle départage avec le coût parcouru.

bool operator()(Node<T> const* a, Node<T> const* b) const
{
    // f = g (coût parcouru) + h (distance estimée)
    int totalCostA = a->cost + a->targetDistance;
    int totalCostB = b->cost + b->targetDistance;

    if (totalCostA == totalCostB)
        return a->cost < b->cost;

    return totalCostA > totalCostB;
}

La boucle de recherche

On retire le meilleur nœud de la file et on met à jour le coût de ses voisins. Une case occupée par un autre agent est ignorée, ce qui permet de contourner les agents en temps réel. Le chemin se reconstruit ensuite en remontant les pCameFrom.

while (!queue.empty())
{
    Node<Tile>* curr = queue.top();
    queue.pop();
    if (curr->isVisited) continue;
    if (curr == endNode) return endNode;
    curr->isVisited = true;

    for (Node<Tile>* neighbour : curr->vNeighbours)
    {
        if (neighbour->isVisited) continue;
        // case prise par un autre agent : on passe
        if (neighbour->data->pOccupyingAgent != nullptr
         && neighbour->data->pOccupyingAgent != pAgent) continue;

        neighbour->targetDistance = neighbour->data->Distance(endNode->data);
        int newCost = curr->cost + curr->data->Distance(neighbour->data);
        if (newCost < neighbour->cost)
        {
            neighbour->cost = newCost;
            neighbour->pCameFrom = curr;
        }
        queue.push(neighbour);
    }
}
Deux versions

De la 2D à la 3D

La version 2D est affichée avec SFML. La version 3D reprend la même logique sur un moteur 3D en DirectX 12, avec des cases de hauteurs différentes et une caméra qu'on peut faire tourner et zoomer.

Commandes 2D

A + Clic gauche créer un agent
Clic droit ajouter un objectif
B bloquer une case
Tab aperçu du chemin
P patrouille
F1 F2 changer de carte

Commandes 3D

Flèches déplacer le curseur
RShift RCtrl hauteur d'une case
Entrée définir la destination
Pavé num. caméra et zoom
Espace recentrer la caméra
