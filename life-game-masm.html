Life Game MASM

Le jeu de la vie de Conway sur une grille de 100 × 100, affiché dans la console Windows. Une même génération y est calculée de six façons, du C++ simple à l'assembleur x64 puis au SIMD sur des bits. Les six versions sont vérifiées entre elles et comparées par un benchmark intégré.

Implémentations

Six façons de calculer une génération

Toutes les versions lisent la grille courante et écrivent la suivante dans une seconde grille. Une bordure de cellules mortes autour de la grille évite de tester les bords.

GenerationCpp

C++ de référence

Deux boucles, huit voisins additionnés un par un, puis la règle de survie et de naissance. C'est la version qui sert de vérité pour toutes les autres.

GenerationASM · fonctions.asm

Assembleur MASM x64

La même boucle écrite à la main en assembleur, appelée depuis le C++ selon la convention d'appel Windows x64. La règle s'écrit sans branchement avec sete, and et or.

GenerationSIMD_Old

SIMD v1

Instructions SSE2 : 16 cellules d'un octet traitées par registre de 128 bits. Les cellules en fin de ligne repassent par la boucle scalaire.

GenerationSIMD_V2

SIMD v2

Plus de boucle scalaire : le dernier bloc de chaque ligne recule pour chevaucher le précédent, et recalcule les mêmes cellules sans rien casser.

GenerationSIMD

SIMD v3

Calcul par tuiles de 16 × 16. La somme horizontale de chaque ligne est gardée en registre et sert pour trois lignes de sortie : 3 chargements par bloc au lieu de 9.

GenerationBitsSIMD

Bitboard SIMD

Une cellule par bit : 128 cellules par registre. Les voisins sont additionnés avec des additionneurs complets, comme dans un circuit électronique.

La règle sans branchement en assembleur

Après avoir additionné les huit voisins dans r14b, la nouvelle valeur s'obtient avec deux comparaisons. Une cellule vit si elle a 3 voisins, ou 2 voisins et était déjà vivante.

cmp  r14b, 3
sete bl                 ; bl  = (voisins == 3)
cmp  r14b, 2
sete r15b               ; r15b = (voisins == 2)
and  r15b, [rcx + r12]    ; ... et déjà vivante
or   bl, r15b
mov  BYTE PTR [rdx + r12], bl

Une seule comparaison pour 16 cellules

En SIMD v3, le nombre de voisins vaut la somme du carré 3 × 3 moins le centre. L'astuce : (voisins | centre) == 3 couvre à la fois la naissance (3 voisins) et la survie (2 voisins et vivante).

// Somme des 9 cellules du carré 3x3, moins le centre
const __m128i voisins = _mm_sub_epi8(
    _mm_add_epi8(_mm_add_epi8(hHaut, hMilieu), hBas), centre);

// 3 | x = 3 ; 2 | 1 = 3 ; 2 | 0 = 2
const __m128i vivant = _mm_and_si128(
    _mm_cmpeq_epi8(_mm_or_si128(voisins, centre), three), one);

// La ligne du milieu devient celle du haut : pas de recalcul
hHaut = hMilieu;
hMilieu = hBas;

Compter avec des portes logiques

Dans la version bitboard, un nombre ne tient pas dans un bit. Chaque somme est donc rangée sur deux registres, et trois bits s'additionnent avec un additionneur complet, pour 128 cellules à la fois.

// somme = a ^ b ^ c
// retenue = 1 si au moins deux bits sont à 1
inline NombreDeuxBits AdditionneurComplet(
    __m128i a, __m128i b, __m128i c)
{
    const __m128i aOuExclusifB = OuExclusif(a, b);
    NombreDeuxBits resultat;
    resultat.poids1 = OuExclusif(aOuExclusifB, c);
    resultat.poids2 = Ou(Et(a, b), Et(aOuExclusifB, c));
    return resultat;
}
