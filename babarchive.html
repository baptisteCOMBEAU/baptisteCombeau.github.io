Babarchive

Une bibliothèque C++20 qui range des fichiers dans une archive .babar, et l'outil en ligne de commande qui va avec. Les fichiers sont compressés et extraits par blocs avec zlib : quelle que soit sa taille, un fichier n'est jamais chargé entier en mémoire.

Mon rôle

Ce que j'ai fait

  • Compression et extraction en flux par blocs avec zlib, vérification de la taille et du CRC32
  • Extraction protégée contre les chemins qui sortent du dossier cible, avec des erreurs par fichier qui n'arrêtent pas l'extraction
  • Outil en ligne de commande : création, ajout, extraction, suppression, listing, lecture et visualiseur hexadécimal
  • Documentation technique : API de la bibliothèque, format de fichier, moteur d'assets

Format

Un fichier .babar

Un en-tête fixe, les fichiers les uns à la suite des autres, puis l'index en fin de fichier. L'en-tête donne la position de l'index : on peut lister l'archive sans lire les données. Ce format a été conçu par Vivien.

BlocTailleContenu
BaseHeader24 octetsNombre magique BABA, version, taille des données, position de l'index.
FileHeader24 octets + ext.Taille d'origine, taille stockée, type, flags (compressé…), CRC32, extension.
DonnéesvariableLe contenu du fichier, brut ou compressé par zlib. Un FileHeader et ses données par fichier.
IndexvariableUn descripteur par fichier : nom dans l'archive et position de son FileHeader.

Compresser en flux

Le fichier source est lu par blocs de 16 Ko (réglable). Chaque bloc met à jour le CRC32 puis passe dans deflate, et la sortie est écrite tout de suite dans l'archive. La taille compressée n'étant connue qu'à la fin, on réserve la place de l'en-tête et on revient l'écrire après.

do
{
    _in.read(inChunk.data(), m_chunkSize);
    const auto n = static_cast<uInt>(_in.gcount());

    crc = crc32(crc, (const Bytef*)inChunk.data(), n);
    flush = _in.eof() ? Z_FINISH : Z_NO_FLUSH;
    zs.next_in  = (Bytef*)inChunk.data();
    zs.avail_in = n;

    do  // vider deflate tant que le tampon de sortie est plein
    {
        zs.next_out  = (Bytef*)outChunk.data();
        zs.avail_out = outChunk.size();
        ret = deflate(&zs, flush);

        const std::size_t produced = outChunk.size() - zs.avail_out;
        _out.write(outChunk.data(), produced);
        _fHeader.fixed.compressedSize += produced;
    } while (zs.avail_out == 0);
} while (flush != Z_FINISH);

_out.seekp(pos);  // retour à l'en-tête réservé
_out.write((const char*)&_fHeader, sizeof(FileHeaderFixed));

Ne rien écrire hors du dossier cible

Un nom de fichier dans l'archive peut contenir ../ ou un chemin absolu. Avant d'écrire, le chemin de destination est normalisé puis comparé au dossier d'extraction : s'il en sort, le fichier est ignoré et signalé, et l'extraction continue avec les suivants.

fs::path const root = _unpackLocation.lexically_normal();

for (auto& desc : m_descriptors)
{
    fs::path rel = fs::path(desc.name).relative_path()
                                      .lexically_normal();
    fs::path dst = (root / rel).lexically_normal();
    fs::path check = FileHelper::RelativeTo(dst, root);

    if (rel.empty() || check.empty() || *check.begin() == "..")
    {
        err.details.push_back(/* "invalid file name ..., skipped" */);
        continue;  // les autres fichiers sont extraits
    }
    ...
}

Vérifier ce qui sort

L'extraction suit le même principe à l'envers : lecture par blocs, inflate, écriture immédiate. Le CRC32 est recalculé sur les octets décompressés. Une archive tronquée ou modifiée renvoie une erreur précise au lieu d'un fichier faux.

if (ret != Z_STREAM_END)
    return Error::Io("compressed data stream is incomplete");

if (written != _fHeader.fixed.uncompressedSize)
    return Error::Io("unpacked size doesn't match the file header");

if ((uint32_t)crc != _fHeader.fixed.crc32)
    return Error::Io("crc32 mismatch, the archive may be corrupted");
Outil

La ligne de commande

L'exécutable Babarchive s'appuie uniquement sur la bibliothèque. Chaque commande est déclarée dans une table avec son usage et son nombre d'arguments minimum et maximum : la même table valide l'appel et génère l'aide.

CommandeAliasRôle
--create--cCrée une archive vide.
--pack--pAjoute un fichier ou un dossier, avec compression en option.
--unpack--uExtrait toute l'archive dans un dossier.
--read--rdExtrait un seul fichier vers un fichier de sortie.
--remove--rRetire un fichier de l'archive.
--list--lListe le contenu : nom, extension, taille d'origine, taille stockée et taux de compression.
--hex--xAffiche n'importe quel fichier en hexadécimal, une archive par exemple.
