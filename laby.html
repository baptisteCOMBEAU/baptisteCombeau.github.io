Laby

Un prototype de jeu de survie coopératif aux accents roguelike, inspiré du film Le Labyrinthe : il faut survivre dans un labyrinthe qui s'agrandit, en rassemblant des ressources pour tenir les nuits. Le jeu tourne sur un moteur maison en C++ et DirectX 12, organisé autour d'un ECS. J'y ai écrit le moteur physique.

Moteur physique

De la détection à la réponse

La physique tourne sous forme de systèmes ECS, exécutés à chaque frame dans cet ordre. Chaque étape réduit le travail de la suivante.

Intégration→ Broad phase→ Narrow phase→ Résolution→ Événements
PhysicIntegrateSystem

Intégration

Forces, gravité, amortissement et résistance de l'air, puis vitesse angulaire via le tenseur d'inertie. Les corps presque immobiles s'endorment pour ne plus coûter de calcul.

BroadPhaseSystem

Broad phase

Une grille de hachage spatiale range chaque collider dans les cellules que couvre sa boîte englobante. Seuls les objets qui partagent une cellule forment une paire candidate.

NarrowPhaseSystem

Narrow phase

Tests exacts sphère–sphère, sphère–OBB et OBB–OBB par SAT sur 15 axes, avec construction des points de contact face–face et arête–arête.

PhysicSystem

Résolution

Impulsions accumulées sur la normale et en friction, restitution, plusieurs itérations de vitesse, puis correction des pénétrations restantes.

OnCollision · OnTrigger

Événements

Les collisions et les zones de déclenchement sont transmises aux scripts de gameplay sous forme de callbacks.

Des paires sans doublon

Deux objets peuvent se croiser dans plusieurs cellules de la grille. Chaque paire est donc rangée dans un ordre fixe (plus petit identifiant d'abord), triée, puis dédoublonnée avant le test de boîtes englobantes.

for (EntityId src : bucket.dynamic)
    for (EntityId tgt : bucket.all)
    {
        if (src == tgt) continue;
        // (A,B) et (B,A) deviennent la même paire
        EntityId lo = (src < tgt) ? src : tgt;
        EntityId hi = (src < tgt) ? tgt : src;
        m_pairKeys.emplace_back(lo, hi);
    }

std::sort(m_pairKeys.begin(), m_pairKeys.end());
m_pairKeys.erase(std::unique(m_pairKeys.begin(),
                 m_pairKeys.end()), m_pairKeys.end());

if (shapeA.aabb.Overlaps(shapeB.aabb))
    m_candidatePairs.push_back({ lo, hi });

Une impulsion accumulée

L'impulsion d'un point de contact est calculée avec la masse effective, qui tient compte de la rotation des deux corps. Le total accumulé ne peut jamais devenir négatif : un contact pousse, il ne tire pas.

const float effectiveMass =
    rigidA.massInverse + rigidB.massInverse +
    ComputeAngularMassTerm(rA, normal, rigidA.inertiaTensorWorldInverse) +
    ComputeAngularMassTerm(rB, normal, rigidB.inertiaTensorWorldInverse);

float deltaImpulse = -(1.0f + restitution) * vn / effectiveMass;

// Le cumul reste positif ou nul
const float oldAccumulated = cached.accumulatedNormalImpulse;
cached.accumulatedNormalImpulse = Max(0.0f, oldAccumulated + deltaImpulse);
const float applied = cached.accumulatedNormalImpulse - oldAccumulated;

Mettre les corps en sommeil

Un corps dont les vitesses restent sous un seuil pendant un certain temps s'endort et n'est plus simulé. Un choc avec un autre corps le réveille.

float linearSq  = LengthSq(motion.linearVelocity);
float angularSq = LengthSq(motion.angularVelocity);

bool lowMotion = linearSq < kSleepLinearThreshold
              && angularSq < kSleepAngularThreshold;

if (lowMotion)
{
    motion.sleepTimer += dt;
    if (motion.sleepTimer >= kSleepTimeThreshold)
        motion.Sleep();
}
else
    motion.sleepTimer = 0.0f;
